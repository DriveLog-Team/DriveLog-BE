연동 순서

운영 주소 https://35.216.33.209. 팀 서버가 개인 계정과 운행을 발급합니다. 팀 토큰은 차량·폰 앱에 포함하지 않습니다. 개인 요청에는 해당 사용자의 Authorization: Bearer …가 필요합니다.

1. 출발 등록과 순간 표시

팀 서버가 계정을 발급하고 출발 시각과 참여자를 보냅니다. 전화 버튼과 음성 명령은 출발 기준 밀리초를 사용합니다. 같은 조작을 재시도할 때 markId를 유지합니다.

POST /api/accounts
POST /api/private-trips/departures
PUT /api/private-trips/{id}/marks/{markId}
{"kind":"TAP","atMs":1920000}
PUT /api/private-trips/{id}/voice-marks/{markId}
{"command":"방금 거 저장해줘","atMs":1930000}
GET /api/private-trips/{id}/timeline
2. 주차 후 동의와 원본 전송

같은 sourceId와 명단으로 정차를 등록합니다. 탑승자는 각자 동의하고 만 14세 미만은 지정 보호자도 동의합니다. 위치와 표시 클립 공유는 별도 선택입니다.

POST /api/private-trips
PUT /api/private-trips/{id}/consents/{occupant}/{role}
{"extraction":true,"geminiTranscript":true,
 "useTripContext":false,"shareMarkedClips":false}
PUT /api/private-trips/{id}/media/{side}

UPLOAD부터 소유자가 front·rear를 각각 video/mp4로 보냅니다. Content-Length와 X-Content-SHA256(소문자 hex)이 필요합니다. 파일당 최대 8 GiB, 재생시간 24시간 이하, 긴 변 4096픽셀·총 4096×2160픽셀 이하입니다. 지정한 오디오 소스에는 음성이 있는 트랙이 필요합니다. 편집 시작 전 한쪽만 교체할 수 있습니다.

3. 추천 확인과 재편집
POST /api/media/jobs
{"tripId":"trip-…","profile":"STORY_15"}
GET /api/media/jobs/{id}
POST /api/media/jobs/{id}/edits
{"id":"moment-001","title":"처음 본 바다"}

202 응답의 jobId를 저장하고 QUEUED·RUNNING 동안 조회합니다. 서버 재시작 후에도 같은 ID를 사용합니다. READY여도 cards가 비어 있을 수 있습니다. 원본은 보호 초안 생성 직후 파기됩니다. 재편집은 새 jobId를 반환합니다.

4. 보관함 확정과 휴대폰 저장
POST /api/private-trips/{id}/finalize
{"jobId":"편집 작업 UUID","moment":"moment-001"}
GET /api/library
GET /api/library/{id}/clip
POST /api/library/{tripId}/handoffs

저장 성공 후 보관함을 갱신합니다. QR의 qrImage를 표시하면 휴대폰에서 확인 후 MP4를 내려받습니다. 5분 만료 또는 1회 사용 후 다시 발급합니다. 토큰과 QR 이미지는 로그에 남기지 않습니다.

오류가 났을 때

400 · 422
파일 길이·해시·영상 규격과 지정 오디오를 확인한 뒤 같은 쪽으로 다시 전송합니다. 잘못된 교체 요청은 기존 영상을 보존합니다.
401 · 403
개인/팀 인증과 탑승자·보호자의 동의 상태를 확인합니다.
409
같은 트랙 전송이나 편집이 진행 중인지 확인합니다. 초안이 생성되면 원본 교체가 닫힙니다.
429 · 507
각각 편집 대기열과 디스크 용량 부족입니다. 잠시 후 재시도하고 반복되면 운영자에게 알립니다.
503
보관함 저장 시 같은 jobId와 moment로 재시도합니다.
FAILED
상태 조회를 멈춥니다. 외부 AI 응답을 확인하지 못한 작업은 자동 재전송을 멈출 수 있습니다. 새 작업은 사용자 재시도로 등록합니다.

시연과 실서비스 범위

시연에서 연결할 기능

합성 전·후방 MP4와 발급된 개인 계정으로 표시·동의·추천·편집·저장·QR을 연결합니다. 대화 추천은 Gemini가 맡고 도로 블러와 보행자 구간 제외는 서버에서 처리합니다. 영상 보호 품질은 공유 전에 확인합니다.

실서비스에 남은 구현

실차 카메라 자동 공급과 실제 주행 상태에 따른 화면 잠금, 로그인·초대와 보호자 관계 확인, Gleo 직접 연동, 인스타그램 스토리·카카오톡 작성기 호출은 별도 구현·기기 검증이 필요합니다.
