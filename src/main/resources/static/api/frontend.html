연동 순서

운영 주소 https://35.216.33.209. 팀 서버가 개인 계정과 운행을 발급합니다. 팀 토큰은 차량·폰 앱에 포함하지 않습니다. 개인 요청에는 해당 사용자의 Authorization: Bearer …가 필요합니다.

1. 출발 등록과 순간 표시

팀 서버가 계정을 발급하고 출발 시각과 참여자를 보냅니다. 전화 버튼과 음성 명령은 출발 기준 밀리초를 사용합니다. 같은 조작을 재시도할 때 markId를 유지합니다.

POST /api/accounts
POST /api/private-trips/departures
PUT /api/private-trips/{id}/marks/{markId}
{"kind":"TAP","atMs":1920000}
PUT /api/private-trips/{id}/voice-marks/{markId}
{"command":"방금 거 저장해줘","atMs":1930000}
GET /api/private-trips/{id}/timeline
2. 주차 후 동의와 원본 전송

같은 sourceId와 명단으로 정차를 등록합니다. 탑승자는 각자 동의하고 만 14세 미만은 지정 보호자도 동의합니다. 위치와 표시 클립 공유는 별도 선택입니다.

POST /api/private-trips
PUT /api/private-trips/{id}/consents/{occupant}/{role}
{"extraction":true,"geminiTranscript":true,
 "useTripContext":false,"shareMarkedClips":false}
PUT /api/private-trips/{id}/media/{side}

UPLOAD부터 소유자가 front·rear를 각각 video/mp4로 보냅니다. Content-Length와 X-Content-SHA256(소문자 hex)이 필요합니다. 파일당 최대 8 GiB, 재생시간 24시간 이하, 긴 변 4096픽셀·총 4096×2160픽셀 이하입니다. 지정한 오디오 소스에는 음성이 있는 트랙이 필요합니다. 편집 시작 전 한쪽만 교체할 수 있습니다.

4. 보관함 확정과 휴대폰 저장
POST /api/private-trips/{id}/finalize
{"jobId":"편집 작업 UUID","moment":"moment-001"}
GET /api/library
GET /api/library/{id}/clip
POST /api/library/{tripId}/handoffs

저장 성공 후 보관함을 갱신합니다. 개인 재생본은 동의된 장소를 표시할 수 있습니다. QR 다운로드와 Android 스토리에는 출발지·도착지·이벤트 장소 레이어를 뺀 공유본을 전달합니다. 빌트인 캠이 속도나 좌표를 영상에 새긴 경우, 정차 등록 때 source.shareMasks에 표시 영역을 지정하세요. 전방이 위쪽, 후방이 아래쪽인 1080×1920 합성 프레임에서 픽셀 단위로 지정합니다. 예: [{"x":0,"y":860,"width":1080,"height":100}]. 지정 영역은 공유본에서 검게 가립니다. 기기별 표시 영역과 이동 여부를 미리 확인하세요. 이전 위치 포함 클립에 공유본이 없으면 QR 발급은 409입니다. QR의 qrImage를 표시하면 휴대폰에서 확인 후 MP4를 내려받습니다. 5분 만료 또는 1회 사용 후 다시 발급합니다. 토큰과 QR 이미지는 로그에 남기지 않습니다.

동승자 초대와 여행 앨범

DRIVING에서 운전자가 링크를 한 사람에게 전달합니다. 동승자는 휴대폰에서 링크를 열어 이름을 입력합니다. 탑승자별로 별도 링크를 발급합니다. 링크 수락과 추출·분석 동의는 별개입니다.

초대·재시도
POST /api/private-trips/{id}/invites
{"under14":false}
→ {"url":"https://…/api/join.html#…","expiresAt":"…"}
PUT /api/private-trips/{id}/display-name
{"displayName":"은서"}

만 14세 미만은 under14=true와 같은 차에 등록된 성인 guardian UUID를 지정합니다. 링크는 30분 동안 한 기기가 사용할 수 있고 주차 등록 시 마감합니다. 자체 앱은 POST /api/private-trips/{id}/join으로 code, displayName, claimKey를 보내세요. claimKey는 32바이트 난수를 패딩 없는 base64url로 인코딩하며 같은 요청 재시도에 유지합니다. URL과 토큰을 로그에 남기지 않습니다.

누가 어디서 남겼는지 표시

GET timeline의 entries에서 authorName, mark.author, place, mark.atMs를 읽습니다. 장소는 전원 위치 동의 후 등록한 사건 중 30초 이내 가장 가까운 라벨입니다. 양쪽 거리가 같고 라벨이 다르거나 근거가 없으면 null입니다. 위치는 동의·맥락 등록 이후 표시됩니다.

개인 선택과 보관
PUT /api/private-trips/{id}/picks/{markId}
POST /api/private-trips/{id}/finalize
GET /api/library

안전한 클립이 생성된 내 표시는 기본 선택입니다. 초안 READY에서 재생 가능한 다른 표시도 내 목록에 추가할 수 있습니다. 소유자가 최종 편집본을 확정하면 각자의 표시 클립과 추가 선택이 함께 보관됩니다. 잘라낸 시점은 최종 편집본에 연결되지 않습니다. 목록 항목별 clipUrl을 사용하세요. 기존 항목의 URL이 없으면 /api/library/{tripId}/clip을 사용합니다. 동승자 재생에는 현재의 전원 공유 동의가 필요합니다. 추출 철회 시 공동 보관본도 삭제됩니다.

카카오톡·인스타그램 연동 가능 범위

카카오톡 공유 SDK는 사용자가 채팅방을 선택해 링크 메시지를 전송합니다. 개인 보관 URL에는 인증이 필요하고 일회 QR은 한 번만 사용할 수 있습니다. 여러 사람이 보는 공유 링크는 별도 권한 설계가 필요합니다. 파일은 폰에 받은 MP4를 OS 공유 메뉴로 전달해 수신 앱 지원을 확인합니다. 카카오 공식 가이드

Android 스토리 공유 · 휴대폰에 DriveLog 스토리 앱과 Instagram을 설치하고 DriveLog 공개 Meta 앱 ID를 한 번 설정합니다. QR을 Android Chrome에서 열고 ‘인스타 스토리에 공유’를 누르면 앱이 POST /api/handoffs/redeem으로 받은 MP4를 스토리 작성기에 전달합니다. 게시 여부는 사용자가 결정합니다. 앱이 없거나 iPhone을 쓰면 ‘MP4 내려받기’를 선택하세요. 현재 Instagram 실기기 검증은 대기 중입니다. 릴스는 내려받은 MP4를 릴스 작성기에서 선택할 수 있습니다. 릴스 작성기로 직접 넘기는 기능은 미구현입니다. 서버 게시 API는 게시 권한을 부여한 프로 계정 대상이며 Facebook Login 경로의 스토리는 비즈니스 계정 조건이 있습니다. DriveLog는 SNS에 자동 게시하지 않습니다. Meta 게시 API

오류가 났을 때

400 · 422
파일 길이·해시·영상 규격과 지정 오디오를 확인한 뒤 같은 쪽으로 다시 전송합니다. 잘못된 교체 요청은 기존 영상을 보존합니다.
401 · 403
개인/팀 인증과 탑승자·보호자의 동의 상태를 확인합니다.
409
같은 트랙 전송이나 편집이 진행 중인지 확인합니다. 초안이 생성되면 원본 교체가 닫힙니다.
429 · 507
각각 편집 대기열과 디스크 용량 부족입니다. 잠시 후 재시도하고 반복되면 운영자에게 알립니다.
503
보관함 저장 시 같은 jobId와 moment로 재시도합니다.
FAILED
상태 조회를 멈춥니다. 외부 AI 응답을 확인하지 못한 작업은 자동 재전송을 멈출 수 있습니다. 새 작업은 사용자 재시도로 등록합니다.

시연과 실서비스 범위

시연에서 연결할 기능

합성 전·후방 MP4와 발급된 개인 계정으로 표시·동의·추천·편집·저장·QR을 연결합니다. 대화 추천은 Gemini가 맡고 도로 블러와 보행자 구간 제외는 서버에서 처리합니다. 영상 보호 품질은 공유 전에 확인합니다.

실서비스에 남은 구현

실차 카메라 자동 공급과 실제 주행 상태에 따른 화면 잠금, 정식 로그인과 보호자 관계 확인, Gleo 직접 연동, iOS 스토리 공유와 카카오톡 작성기 호출은 추가 구현이 필요합니다.
